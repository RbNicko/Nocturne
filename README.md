# Nocturne
Nocturne is my personal music player that I built from scratch. The goal of this project is to build my ultimate music player, adding features as they come to mind, while I learn to build, program, and understand the Klotin language. This project is being developed using artificial intelligence agents that correct errors—both in syntax and in the code’s structure—though the project is not 100% AI-generated. It’s still in the development phase and isn’t intended for distribution. If anyone comes across it, please feel free to give me advice on how to improve both the app and my coding. Thanks <3
